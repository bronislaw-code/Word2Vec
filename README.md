# 🎬 Exploration des Word Embeddings (Word2Vec)

Projet d'apprentissage automatique et de traitement du langage naturel (NLP). 
Entraînement d'un modèle Word2Vec sur 50 000 critiques de films pour capturer les relations sémantiques et vectorielles des mots.

### 🌐 Démo en direct
Cliquez sur le badge ci-dessous pour tester l'application Streamlit :

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://word2vec-word-movies-bronislaw.streamlit.app)

### 🛠️ Fonctionnalités
- Recherche des 10 mots les plus proches (Similarité Cosinus).
- Arithmétique sémantique des mots (ex : *great - good + bad = terrible*).
